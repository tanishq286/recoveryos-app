## 2. Confirmed root causes

| Symptom | Cause | Layer |
|---|---|---|
| "NA C/O", "NA K ‐", "NA 23," as father/spouse | The source prints `NA` for an unknown relative (placeholder). pdf.js merges text sharing a baseline into one run, so the first token of the **Address** cell arrived in the relative's surname cell; columns were assigned by nearest header centre, which fails for left-set data under centred headers. | Source placeholder + extraction + normalization |
| Amount `1234.50 02`, missing day in dates | Same run merging: the date's day sat in the amount run. `number()` then stripped spaces, reading `1234.5002`. Rounding hid it for 2-decimal amounts; `750 02` would have become 75,002. | Extraction + parsing |
| "10 Amount for unclaimed and" investment types | Same run merging, plus `…-9Amount` with no space. | Extraction |
| 402 skipped rows | Long first names wrap inside the cell; the wrapped line was taken as a new holder with no amount. | Record grouping |
| "Agarwal" returns 5 matches | One word typed into the name box became a **first** name, so surnames were never searched. 67 records have surname AGARWAL and 113 more carry it in another column. | Search input resolution |
| Calculator says "Live" for a 30 Oct quote | The provider's quote time was fetched but discarded; the calculator showed the quote time as "Live" while company pages showed our fetch time. | Data model + labels |
| Sign-in codes not delivered by SMS | Without an SMS provider the API fell back to an in-app code mode. Replaced: codes are never displayed, returned or logged, and sign-in pauses honestly until a provider is configured. | Auth configuration |

## 3. What changed

Security and identity:
- OTP: the code is never returned or shown in any environment. Without an SMS
  provider, production answers 503 with an honest message (`GET /auth/otp/status`
  drives the UI); no challenge is created. Console sender refused in production.
  The development administrator number is refused in production. Undelivered
  codes are invalidated.
- eSign: only a provider webhook is "Aadhaar eSign"; in-portal acceptance and
  the development simulator are labelled as such everywhere (events, PDF stamp,
  portal). Signing no longer releases the folio. Webhooks update conditionally
  (replays and races cannot sign twice) and the body hash is audited.
- Folio release (lead or case) needs a recorded reason; a case release also
  needs a verified PAN. Nothing is released while another person's claim is
  open unless the reviewer clears the flag and records the outcome.
- Claims run in one transaction with per-record advisory locks (work through
  PgBouncer transaction pooling). A competing claim flags **both** claimants'
  requests; neither learns about the other.
- "Holder ID … is a different person" replaced with record-group wording.

Data:
- PDF reader `statement-reader/2026.11.2`: merged runs split into words with
  glyph-width estimates; column boundaries from the emptiest gutter left of the
  next column's cell starts; wrapped name lines joined and flagged.
- Additive migration `20261105000000_provenance`: `source_documents`
  (URL, company, type, period, publication + basis, retrieval, SHA-256, parser,
  status, review, publication, quantity basis), `source_rows` (raw cells
  AES-GCM encrypted, immutable by trigger, row reference, issues, status),
  holder columns (raw relative, validation status/issues, review status,
  source links, quantity basis/effective date), job retry and parser columns,
  price quote/attempt/error columns.
- Validation rules in `packages/shared/src/identity.ts`; quarantined records
  are stored but excluded from search, stats and company counts until staff
  publish or withdraw them (`/admin/ingestion/quarantine`).
- `npm run reprocess:sources -w @finsol/db`: dry run by default, read-only
  session; `--apply` backs up, applies, quarantines records not reproduced;
  `--rollback` restores. Idempotent (verified: second pass changes nothing).
- Admin dashboard `/admin/coverage` and import retry.

Search, prices and valuation:
- Coverage and freshness with every result list and every "no match"; explicit
  states for loading, no match, unavailable (with retry, never shown as no
  match), restricted details, truncated lists, unknown values; matches grouped
  exact / partial / spelling variant; one-word searches cover all name parts.
- Prices: quote time and fetch time stored and shown separately; status labels
  Delayed / Latest available (market closed) / Last known (stale) / Unavailable
  / Your price, from one shared function used by calculator, company page and
  PDF. Fresh quotes are written through so all three agree. No fallback prices.
- Valuation: unknown price stays unknown (totals say what is excluded);
  historical dividends shown separately, never in the estimate; purchase-year
  range when events fell in that year; missing history flagged; same-day split
  then bonus in a fixed order. PDF renamed "Estimated Share Valuation".

Public content: privacy and terms pages (owner items in
`docs/privacy-terms-review.md`), footer and login links, "100% Confidential"
replaced, contact cards no longer hidden by entrance animation, partner locator
empty states split.

## 5. Release plan (needs approval: nothing below has been run in production)

1. Merge after review. Deploy the API first (`finsolenterprises-api`,
   prj_QqBtbwNXBu9cJzn43PJK6mVSDaRm), then the web (`finsolenterprises`,
   prj_exEsoErcfYN22dJ8q4vxguJjSGCC), team team_jkvEsUV82fUbTJTyDTZlpMZa.
   Effect: OTP sign-in pauses until an SMS provider is keyed.
2. Back up: Neon branch or point-in-time restore marker before migrating.
3. `prisma migrate deploy` (additive; no rewrites, no drops).
4. Dry run again, then `reprocess:sources --apply --confirm-production` with
   the production folio keys. The backup table name is printed.
5. Verify with `audit:coverage` and the public search.
6. Provision the real administrator with `SEED_ADMIN_PHONE` and retire any
   development account (details in the private release notes).

Rollback: `reprocess:sources --rollback backup_folios_<time>` restores every
changed column and withdraws added records; code rollback is a Vercel
instant rollback; the migration only adds objects, so old code runs on the new
schema.

- SMS OTP provider (MSG91 with DLT template, or Twilio): credentials and contract.
- eSign provider (Digio or Leegality): contract, credentials, and webhook
  signature details confirmed against the provider's documentation.
- More holder data: further company statements (public downloads or
  authorised uploads) or a licensed registrar/IEPF feed. MCA's IEPF search is
  CAPTCHA-protected and is not scraped.
- Owner review of privacy/terms items.
- Web function region: the web project runs in iad1 while the API and
  database are in Singapore; moving the web to sin1 would remove a
  trans-Pacific hop from every search.
